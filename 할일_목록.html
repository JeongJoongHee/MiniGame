1. 랭킹을 서버에 연결 (2단계) 끝 · 2026-09-11

    4. 만들어진 앱에서 광고 단위 > 광고 단위 추가 → 전면 광고(Interstitial) 를 고릅니다.
      이름은 아무거나 (예: 게임오버_전면). 나머지 설정은 기본값으로 두세요.
    5. 두 가지 값을 복사해서 저에게 주세요. 
      앱 ID        ca-app-pub-0000000000000000~1111111111
광고 단위 ID  ca-app-pub-0000000000000000/2222222222
      가운데 기호가 다릅니다 — 앱 ID 는 ~(물결), 광고 단위 ID 는 /(빗금).
      앱 ID 는 앱 > 앱 설정, 광고 단위 ID 는 광고 단위 목록에 있습니다.

    이 두 값은 비밀이 아닙니다 (앱 안에 들어가는 값입니다). 그냥 알려 주시면 됩니다.

  • 자세한 방법

    AdMob 은 승인된 스토어로 배포된 앱에만 실제 광고를 내보냅니다. 목록은 정책 페이지에 있고 바뀝니다.

    1. AdMob 화면 아래쪽 또는 구글 검색으로 "AdMob 프로그램 정책" 문서를 엽니다.
    2. "앱 배포" / "허용되는 배포 채널" 같은 항목에서 원스토어가 있는지 봅니다.
    3. 확실하지 않으면 AdMob 고객센터에 문의하시는 것이 가장 확실합니다.

    결과에 따라 제가 할 일이 정해집니다. 목록에 있으면 그대로 두면 되고, 없으면 원스토어용 빌드에서만 광고를 끄도록 스위치를 하나 넣겠습니다 (설정에 adsEnabled 가 이미 있습니다).

    급한 일은 아닙니다. 플레이스토어에 올리시므로 광고 자체는 문제없습니다.

Claude

내 광고를 내가 누르면 안 됩니다. 계정이 정지되고 되돌리기 어렵습니다. 확인은 테스트 광고로만 하세요. 폰에서 실제 광고가 뜨더라도 누르지 마세요.

3. 서명 · 정책 · 스토어 (4단계)

사용자

  • 자세한 방법

    쉬운 방법 — Unity 안에서 만들기

    1. Unity 메뉴 Edit > Project Settings > Player
    2. 안드로이드 탭 → Publishing Settings 를 폅니다
    3. Keystore Manager → Keystore > Create New > Anywhere...
    4. 저장 위치는 프로젝트 폴더 바깥으로 하세요. 예: D:\00.JumpJump_열쇠\jumpjump.keystore
      (프로젝트 안에 두면 git 에 딸려 들어갈 수 있습니다)
    5. 비밀번호를 정합니다. 키스토어 비밀번호와 키(Alias) 비밀번호 두 개인데, 같게 하셔도 됩니다.
    6. Alias 는 jumpjump 정도. 유효기간은 기본값(50년)이 좋습니다.

    명령으로 만드는 방법 (같은 결과입니다)

    "C:\Program Files\Unity Hub\6000.0.81f1\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK\bin\keytool.exe" ^
  -genkeypair -v -keystore D:\00.JumpJump_열쇠\jumpjump.keystore ^
  -alias jumpjump -keyalg RSA -keysize 2048 -validity 18250

    세 가지를 반드시 따로 적어 두세요. ① .keystore 파일 ② 비밀번호 두 개 ③ Alias 이름. USB 와 클라우드처럼 서로 다른 두 곳에 보관하시고, 비밀번호는 파일 이름이 아니라 메모로 남기세요.

    잃어버리면 원스토어 쪽은 같은 앱을 영영 갱신할 수 없습니다. (플레이스토어는 Play 앱 서명을 쓰면 업로드 키를 다시 발급받을 수 있습니다)

    키스토어 파일과 비밀번호는 저에게 주실 필요가 없습니다. 빌드할 때 Unity 창에 직접 넣으시면 됩니다.

  • 자세한 방법
    1. play.google.com/console → 구글 계정으로 로그인
    2. 계정 유형을 개인 / 조직 중에 고릅니다. 개인으로 등록하면 스토어에 이름이 공개될 수 있습니다 (조직으로 하려면 사업자 등록이 필요합니다).
    3. 신원 확인 — 신분증과 주소를 요구합니다. 며칠 걸릴 수 있습니다.
    4. 등록비 25달러 결제 (한 번만).
    5. 승인되면 "앱 만들기" 로 앱 자리를 만듭니다.

    새로 만드는 개인 계정에는 "비공개 테스트" 요건이 붙습니다 — 일정 인원의 테스터가 일정 기간 동안 앱을 써 봐야 정식 출시를 신청할 수 있습니다. 이 규정은 자주 바뀌므로 가입 화면에 나오는 조건을 그대로 따르세요. 지인 계정을 미리 모아 두시면 나중에 덜 기다립니다.

  • 자세한 방법
    1. 원스토어 개발자 센터에 가입합니다 (개인/사업자 선택).
    2. 본인 확인과 정산 정보(계좌)를 넣습니다. 국내 서비스라 절차가 한국어입니다.
    3. 앱을 새로 만들고 APK 를 올립니다. (제가 원스토어용 APK 를 구워 드립니다)
    4. 등급 분류 — 게임은 등급이 필요합니다. 보통 스토어 안의 설문으로 처리됩니다. "광고 포함"을 사실대로 체크하세요.

    순서를 정하자면 플레이스토어를 먼저 하시는 편이 낫습니다. 심사 기준이 더 까다로워서, 거기서 통과하면 원스토어는 대체로 수월합니다.

  • 자세한 방법

    스토어에 "주소(URL)" 를 넣어야 하므로, 어딘가에 공개된 웹 페이지가 하나 있어야 합니다. 내용은 제가 써 드리니 올리는 것만 하시면 됩니다.

    돈 안 드는 곳들 (아무거나 하나)

    • 네이버 블로그 · 티스토리 — 글 하나 쓰고 그 주소를 쓰면 됩니다. 가장 쉽습니다.
    • 구글 사이트 도구(Google Sites) — 페이지 한 장짜리 사이트를 만들 수 있습니다.
    • GitHub Pages · Notion 공개 페이지 — 익숙하시면 이쪽도 좋습니다.

    조건 : 로그인 없이 누구나 볼 수 있어야 하고, 주소가 바뀌지 않아야 합니다.

    제가 쓸 초안에는 이런 내용이 들어갑니다 — 무엇을 모으는지(별명 · 점수 · 광고 식별자), 왜 모으는지, 누구에게 전달되는지(구글 Firebase / AdMob), 문의 이메일. 문의용 이메일 주소는 정해서 알려 주세요 — 공개되는 주소입니다.

  • 자세한 방법

    그림 (대략의 크기입니다. 스토어 화면에 정확한 값이 나옵니다)

    • 앱 아이콘 512×512 PNG — 폰 홈 화면 아이콘과 별개로 스토어에 올리는 그림입니다. 사용자께서 그려 주셔야 합니다.
    • 그래픽 이미지(배너) 1024×500 — 스토어 목록 맨 위에 걸리는 가로 그림입니다.
    • 폰 스크린샷 2장 이상 — 제가 게임 화면으로 만들어 드릴 수 있습니다. 타이틀 · 로비 · 점프점프 · 활쏘기 · 랭킹 창이 이미 캡처되어 있습니다.

    글 — 짧은 설명(한 줄)과 자세한 설명(여러 줄)이 필요합니다. 초안은 제가 써 드립니다. 읽어 보시고 고치시면 됩니다.

    설문

    • 연령 등급(IARC) — 폭력·선정성 등을 묻는 설문에 답하면 등급이 정해집니다. 이 게임은 낮은 등급이 나올 것입니다.
    • "광고 포함" 을 반드시 사실대로 체크하세요. 나중에 문제가 되는 대표적인 항목입니다.
    • 데이터 세이프티 — 무엇을 모으는지 신고하는 양식입니다. 넣을 내용은 제가 정리해 드립니다.
  • 자세한 방법
    1. 정사각형 투명 배경 PNG 로 그립니다. 512×512 정도면 충분합니다. 여백은 신경 쓰지 않으셔도 됩니다 — 자동으로 잘라 냅니다.
    2. 파일 이름을 Rank.png 로 합니다.
    3. D:\00.JumpJump\ 또는 @리소스 추가_2차\ 같은 폴더에 넣습니다.
    4. Unity 에서 Tools > Arcade > Build All Scenes.

    로비의 톱니바퀴와 같은 크기로 들어가니, 톱니바퀴와 비슷한 굵기·색으로 그리시면 잘 어울립니다. 트로피든 왕관이든 1·2·3 시상대든 좋습니다.

4. 폰에서 확인 (5단계)

여기서부터는 제가 확인해 드릴 수 없습니다. 광고와 통신은 배치 모드로 검증되지 않습니다.

APK 를 폰에 넣는 방법
  1. 제가 D:\00.JumpJump\JumpJump.apk 를 구워 드립니다 (10분 이상 걸립니다).
  2. USB 로 폰을 연결해 파일을 옮기거나, 카카오톡 "나에게 보내기" 로 보내셔도 됩니다.
  3. 폰에서 그 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 을 허용하라는 안내가 나오면 허용해 주세요.
  4. 이미 깔려 있던 같은 앱이 있으면 서명이 달라 설치가 안 될 수 있습니다. 그때는 기존 앱을 지우고 다시 설치하세요. (기록도 같이 지워집니다)
